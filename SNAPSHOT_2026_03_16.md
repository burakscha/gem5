## What This Project Is

Register spilling analysis for RISC-V SPEC CPU2017 benchmarks using gem5 TimingSimpleCPU.

**Goal**: Measure what fraction of instructions/loads/stores are register spills across
17 C/C++ SPEC CPU2017 benchmarks (test / train / refrate input sizes).

**Three metrics per run:**
- **Rate** = ROI spills / ROI instructions
- **Sp/Ld** = ROI spills / ROI loads  (fraction of loads that are spill reloads)
- **Sp/St** = ROI spills / ROI stores  (fraction of stores that are spill writes)

## After Migration: How to Resume

### 1. Check what survived
```bash
cd ~/riscv-spec-register-spilling/gem5
bash status.sh
```

### 2. Relaunch any that are NOT RUN or still stuck

The launch script is `launch_ref_all.sh`. For individual relaunches, the pattern is:
```bash
GEM5=./build/RISCV/gem5.opt
CFG=./configs/deprecated/example/se.py
B=./benchmarks

nohup $GEM5 --outdir=$B/<bench>/m5out_<input> $CFG \
  --cpu-type=TimingSimpleCPU --mem-size=8GB --mem-type=SimpleMemory \
  --cmd=$B/<bench>/<bench>.riscv \
  --options="<args>" \
  > $B/<bench>/<bench>_<input>_run.log 2>&1 &
```

See `launch_ref_all.sh` for exact args per benchmark.

### 3. Special cases to be aware of

- **mcf ref**: Already done in verbose mode (38GB CSV at `benchmarks/mcf/m5out/`).
  Analysis at `benchmarks/mcf/m5out/benchmark_analysis.txt`. Rate=1.98%, 419M spills.
  Does NOT need to be re-run unless you want summary format.
- **parest ref**: SE mode can't read `/proc/cpuinfo` → crashes. Only test+train are possible.
- **x264 ref**: Shows same stats as test — suspect it's using test stats file. Verify
  `benchmarks/x264/m5out_ref/riscv_spill_stats.txt` exists and has correct content.
- **imagick train**: Very low rate (0.1029%) — anomalous, double-check.
- **omnetpp test** and **perlbench test**: Stats files have multiple ROI blocks (benchmark
  runs multiple inputs in one invocation). status.sh uses `tail -1` to read the last block.

## SPEC Build — If Needed Again

```bash
cd cpu2017 && source shrc
rm -rf benchspec/CPU/<bench>/build/build_base_spill.riscv.0000
rm -f  benchspec/CPU/<bench>/exe/*
runcpu --config=bkaya-riscv --tune=base -I --action=build <bench>
```

Config: `cpu2017/config/bkaya-riscv.cfg`
- OPTIMIZE = `-O3 -fno-strict-aliasing`
- CC/CXX: RISC-V cross-compiler with `-I.../gem5/include`
- LDFLAGS: `-L.../m5/out -lm5`
