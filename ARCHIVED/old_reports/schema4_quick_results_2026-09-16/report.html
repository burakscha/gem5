7. Denominators and interpretation

L1 hit rate = L1 hits / (L1 hits + L1 misses)

L2 local hit rate = L2 hits / (L2 hits + L2 misses)

L2 rescue / L1 = L2 hits / L1 accesses

DRAM / L1 = L2 misses / L1 accesses

The weighted-total percentages are recomputed from summed hit/miss populations; they are not arithmetic means of benchmark percentages. A split memory instruction can generate multiple L1 accesses, so cache hit-rate denominators are cache accesses rather than instruction counts.
